Web to Plex

From a page to your *arr queue. No copying, no retyping.

A browser extension that searches a Plex Media Server for whatever's on the page — IMDb, Letterboxd, Rotten Tomatoes, and dozens more — and add it to Plex via *arr or another media manager.

Features

  • Plex It! — a watchlist for sites that don't have one.
  • Download — send an item straight to an NZB or Torrent manager instead of waiting.
  • Find this — right-click search when the auto-match is wrong.
  • Direct Plex URL support, to skip app.plex.tv entirely.
  • Over 40 supported sites, including IMDb, Trakt, Letterboxd, Hulu, Netflix, and YouTube.

Supported managers

  • Radarr & Sonarr — movies and TV, searchable.
  • CouchPotato, Watcher 3 — movies only.
  • Medusa, Sick Beard — TV only.
  • Ombi — searchable, with setup.

Install

Requires Plex Media Server 1.4.3.0 or higher. Configure the extension's settings before first use.
