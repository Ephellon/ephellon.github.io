TTV Tools

Features Twitch doesn't have. Added, quietly, in the background.

A browser extension that puts viewer conveniences onto the Twitch player and chat. Runs unattended once installed.

Features

The full feature set changes as Twitch does and is tracked in the project's wiki rather than fixed here.

Install

  • From the Chrome Web Store — install, adjust, done.
  • From source — download ttv-tools.zip off the latest release, extract it, then load it unpacked via chrome://extensions with Developer mode on.
