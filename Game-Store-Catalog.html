Game Store Catalog

Every platform, one shape. No database required.

A scrape of PlayStation, Xbox, Nintendo, Steam, and Epic Games storefronts, normalized into one JSON schema. Built where no public API exists. Not updated regularly — kept and refreshed by Store Scraper.

Coverage

  • Steam — 172,000+ games
  • Xbox — 16,800+ games (console + PC)
  • Nintendo — 13,700+ games
  • PlayStation — 19,100+ games (PS4 + PS5)
  • Epic Games — 5,800+ games

Format

Every entry is the same shape — name, price, image, purchase link, platform, rating — split into per-letter files for browsing, or one combined file per store.
